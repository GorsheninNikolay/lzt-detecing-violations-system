**Как заполнить план участка**

1. Откройте проект и «План работ». В поле «Участок» выберите место, к которому относятся фотографии. Обычно достаточно участка «Основной участок». Если разные места имеют разные работы, нажмите «Добавить участок», укажите название и «Создать участок». Участок связывает фотографии одного места с его планом; он не является обязательным дополнительным уровнем для простой площадки.
2. В пустом плане нажмите «Добавить первую работу»; для следующих работ — «Добавить работу». Откроется окно «Выберите работу» с поиском по названию или коду. Нажмите на нужную работу в результатах — она появится в плане. Сам поиск ещё ничего не добавляет. «Выбрать другую работу» заменяет выбранную работу, сохраняя введённые сроки и настройки.
3. Укажите «Начало» и «Окончание»: дату и время. Окончание не должно быть раньше начала. Интерфейс использует часовой пояс компьютера. Несколько работ могут идти параллельно.
4. Выберите «Состояние»: «Запланирована», «Активна» или «Завершена». Для выполняемой работы — «Активна»; проверки техники учитывают состояние и время.
5. В блоке «Техника» нажмите «Добавить технику» и выберите нужные типы. Каждый выбранный тип появляется отдельной строкой. По умолчанию он «Ожидается». В этой строке можно изменить условие на «Допускается» или «Не предусмотрена», либо убрать тип крестиком. Можно выбрать несколько типов подряд; «Готово» закрывает выбор.
6. Нажмите «Сохранить план» и дождитесь сообщения «План сохранён». Сохраняются все работы участка. Крестик в заголовке работы удаляет её из черновика; удаление попадёт на сервер после сохранения.

**Что означают условия техники**
«Ожидается» — техника нужна для работы и её отсутствие в пригодной серии может требовать проверки. «Допускается» — техника может присутствовать, но её наличие необязательно. «Не предусмотрена» — явно исключена для этой работы. Неуказанная техника не считается автоматически запрещённой. Ожидания задаёт пользователь по своему плану; помощник не назначает обязательную технику по нормативам.

Доступны экскаватор, самосвал, каток, кран-манипулятор, автобетоносмеситель, бульдозер, грузовик и автокран. Наблюдения на фотографии и отсутствие техники на всей площадке — разные вещи; предупреждение требует проверки человеком.

**Нужен ли ожидаемый этап**
В «Дополнительных настройках» работы есть «Ожидаемый этап работ». Раньше поле называлось «Сценарий анализа». Это указанный человеком этап по плану, а не отдельная модель или команда запуска. Можно оставить «Не указан». Если этап задан, он помогает проверить расхождение с фактическим подтверждённым этапом. Доступны «Земляные работы», «Бетонные работы» и «Дорожные работы».
Для проверки отсутствия катка требуется этап «Дорожные работы», автобетоносмесителя — «Бетонные работы». При выборе такой ожидаемой техники редактор напоминает указать соответствующий этап. Не назначайте его автоматически без данных пользователя.

План изменяют владелец и редактор. Наблюдатель только просматривает и может попросить владельца изменить доступ.

После сохранения откройте «Загрузить фото», выберите тот же участок, проверьте время съёмки и включите «Сопоставить с сохранённым планом». Без плана доступен анализ самих фотографий. Сохранённый анализ связан с выбранной версией плана; последующие изменения не переписывают старые результаты.

Кнопка «Сохранить план» появляется после изменения работ. После сохранения отображается подтверждение; сохранение без изменений не требуется. Технический номер версии и отдельный блок времени в редакторе не показываются. При ошибке загрузки или конфликте появляется «Повторить загрузку»: сначала сохраните свой ввод отдельно и только затем подтвердите замену черновика сохранённым планом.

Импорт Excel: скачайте шаблон или заполненный учебный Excel в «Плане работ», выберите XLSX либо перетащите его в область загрузки. Обязательные столбцы: Работа, Начало, Окончание. Используйте точное уникальное название или ID работы из справочника, технику разделяйте точкой с запятой. Формулы не поддерживаются. Ошибки указаны с номерами строк и блокируют весь импорт. Проверьте предпросмотр и нажмите «Заменить план»: будет создана новая ревизия, предыдущие версии и привязки анализов сохранятся. Даты без времени означают начало и конец дня в часовом поясе проекта. При конфликте версии загрузите файл заново. Учебный шаг завершается после сохранения и чтения новой версии.
