# Интерфейс

React/TypeScript/Vite. Из корня: `npm --prefix web ci`, `npm --prefix web test -- --run`, `npm --prefix web run build`. Готовый `dist` включается в образ веб-сервера. API использует относительный `/api`; nginx перенаправляет его в backend.

Основной путь: проект → участок → фото и согласие на облачную обработку → наблюдения и аналитика мультимодальной модели → отдельное решение человека. Свободное имя техники, отсутствующая рамка/уверенность и старые результаты без аналитики поддерживаются. Архив прошлых экспериментов отделён от демонстрации. Подробнее: [README](../README.md), [путеводитель](../docs/CODE_GUIDE.md).
