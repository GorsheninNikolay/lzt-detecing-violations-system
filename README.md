# Контроль строительства

Приложение помогает разбирать фотографии и видео строительной площадки: находит видимую технику, предлагает этапы работ и сопоставляет наблюдения с планом участка. Результаты содержат разметку и основания сигналов для проверки человеком. Снимок не подтверждает нарушение норм, отсутствие техники на всей площадке или отставание от графика.

В проекте можно хранить планы и историю анализов, приглашать участников, исправлять разметку и просматривать учебные примеры. Фотоанализ использует две YOLO на CPU и Мультимодальную модель; видео выбирает CUDA или CPU и сохраняет размеченный MP4. Для облачного анализа нужен настроенный профиль.

## Запуск

Нужны Node.js/npm, `make`, `curl` и Docker Compose. Отдельно получите исходный каталог `artifacts/dataset/Свод*.xlsx` и веса `artifacts/Models/apoce.pt`, `artifacts/Models/kaggle.pt`.

```sh
make up
```

Приложение доступно на <http://127.0.0.1:8096>. Команда `make down` останавливает контейнеры и сохраняет тома с данными. [Настройка профиля и эксплуатация](infra/deploy/README.md).
