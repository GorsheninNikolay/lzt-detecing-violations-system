Анализ завершён

Требуется проверка

Возможна задержка вывоза грунта. Проверьте подачу самосвалов в зону погрузки.

Это рекомендация для проверки, а не подтверждение нарушения.

Почему сформирована рекомендация

Применённое правило

Вывоз грунта из котлована. Экскаватор ожидается постоянно, самосвал ожидается периодически. Для проверки нужны не менее трёх пригодных кадров одной контролируемой зоны.

Происхождение правила

Демонстрационное правило. Его ревизия и полный применённый снимок зафиксированы в запуске.

Неопределённость

Изображения показывают только наблюдаемый период и не доказывают отсутствие техники на всей площадке.

Период и зона наблюдения

Период: указан в запуске. Зона: зона погрузки котлована.

Рекомендуемая проверка

Уточнить подачу самосвалов в контролируемую зону погрузки за указанный период наблюдения.

Наблюдения по кадрам

Каждое состояние относится только к указанному изображению.
