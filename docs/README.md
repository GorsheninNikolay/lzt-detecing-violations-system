Жюри и заказчику три тематические страницы объясняют результат и его ограничения. Разработчику схемы и ссылки на исходники помогают найти обработку фотографий, правила сравнения и места хранения данных.

Документация описывает текущий код и конфигурацию репозитория. Она не подтверждает точность распознавания или состояние удалённого сервера. Условия независимой проверки качества приведены в [инструкции оценки](../evaluation/hybrid/README.md).

После неудачного анализа редактор может явно отправить сохранённые фотографии ещё раз. Новая обработка может повторно расходовать средства. Она создаёт один связанный анализ и сохраняет исходные фотографии, время съёмки, версию плана и результаты прежних вызовов. Загрузка страницы сама обработку не запускает.

API: `POST /runs/{run_id}/retry` принимает необязательное JSON-тело `{"repeat_processing": true}` (до 1024 байт). Только явное `true` разрешает новую обработку после прежних облачных вызовов. Пустое тело или `false` сохраняют прежнее ограничение: повтор возможен лишь до первого вызова. Повтор запроса к тому же предшественнику возвращает уже созданный `run_id`, в том числе после потери ответа.
