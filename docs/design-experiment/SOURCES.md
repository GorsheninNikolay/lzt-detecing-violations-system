# Sources and adaptation

Adapted Aceternity UI components:
- https://ui.aceternity.com/components/3d-marquee — four-column alternate vertical motion and tilted plane, rewritten with local decorative architectural covers, bounded dimensions, offscreen pause and reduced-motion support.
- https://ui.aceternity.com/components/container-scroll-animation — useScroll/useTransform perspective presentation, reduced to a compact overview illustration. Working evidence photos, boxes and editor geometry are outside every animated/transformed decorative container.

Source read from the official registries: https://ui.aceternity.com/registry/3d-marquee.json and https://ui.aceternity.com/registry/container-scroll-animation.json on 2026-09-28. The applicable official licence is https://ui.aceternity.com/licence (not MIT); a local HTML copy is retained in `licenses/aceternity-licence.html`. Attribution: Aceternity UI, Manu Arora. This is a local end-product experiment, not redistribution of standalone component source or a template library. No publication is performed.

Local adaptations use only motion/react, React and CSS. Covers and the presentation illustration are decorative drawings; photographs in the work area remain original evidence without tilt, filter, perspective or decorative motion.
