# Материалы для жюри

Статус: подготовка выпуска, не финальная сдача. Восьмиклассовая модель не прошла приёмку; проверенные демонстрационные случаи новой версии пока отсутствуют.

Ручная разметка готова: откройте `annotation-review/index.html`, прочитайте `annotation-review/README.md`, экспортируйте JSON и передайте его для проверки. Набор из 100 фотографий не гарантирует покрытие восьми классов; происхождение серий нельзя угадывать.

1. Прочитайте `release-report.md`: фактическая версия и границы проверки.
2. `requirements-coverage.md` связывает требования с реализацией и доказательствами.
3. `demo-checklist.md` определяет условия допуска к показу.
4. `demo-script.md` задаёт порядок показа после получения реальных результатов.

На 26 сентября 2026 проверен старый сервер http://158.160.42.119:8096: readiness отвечает `ready`. Это не адрес готового защищённого выпуска для жюри. Не вводите общий код по HTTP. Новый HTTPS-адрес пока не подтверждён.

Локальный запуск описан в корневом `README.md` репозитория. Инфраструктура: PostgreSQL и MinIO; backend: Python 3.13.15 и uv; frontend: Node.js и npm. Локальная модель требует отдельного допуска и проверенного снимка. Существующий допуск двух классов не подтверждает восемь классов.

Секреты, ключи облака, код доступа и резервные копии пользовательских данных в пакет не включаются.
