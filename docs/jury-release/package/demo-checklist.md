# Проверка перед показом

До выполнения всех пунктов пакет не готов к публичной демонстрации.

- [ ] HTTPS-адрес отвечает; сертификат доверенный; общий код требуется для UI, API и исходных изображений.
- [ ] Проверен точный установленный SHA и допущенный профиль модели.
- [ ] Приёмочный набор утверждён человеком; обязательные сценарии проходят без ложных предупреждений.
- [ ] Остаток бюджета подтверждён долговечным журналом резервов и расходов, включая незавершённые запросы.
- [ ] Очередь свободна; readiness успешна; вход и новая загрузка проверены.
- [ ] Фото сверены по SHA-256, порядок и время каждого кадра соответствуют сохранённому плану.
- [ ] Для каждого шага есть настоящий analysis ID, профиль, ревизия плана, результат и headless-снимок.
- [ ] Проверены история и открытие подтверждающих кадров на ноутбуке и телефоне.
- [ ] Контрольный прогон выполнен на установленной версии.
- [ ] Резервные результаты явно подписаны датой, версией и словами «сохранённый прогон».

Не заполнять пункты по ожиданию или по успешным тестам с подставным наблюдателем.
