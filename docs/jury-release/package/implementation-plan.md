# Ход реализации утверждённого плана

## Цель
Проект и зона → работы календарного плана → подтверждение техники → собственные JPEG/PNG → объяснимый результат с относящимися к работе кадрами. Быстрая проверка этапа и только распознавание — отдельные режимы.

## Обязательный объём
- Восемь этапов: подготовка территории и планировка; снос и демонтаж; земляные работы и котлован; бетонные работы; подъём и монтаж конструкций; дорожные работы; наружные инженерные сети; благоустройство.
- Шаблоны техники, связь с каталогом, подтверждение пользователем, альтернативы без одновременной обязательности, явные ограничения непроверяемых работ.
- Поиск и шкала плана, сопоставление каждого кадра по зоне/времени, параллельные работы и переходы, точные ревизии, совместимость истории и повторов.
- Восемь классов; независимая человеческая разметка и разделение по источникам/сериям; локальный и облачный профили на одинаковом наборе. Выбор прошедшего профиля по классификации, затем задержке, при равенстве локального.
- Пять типов сигналов: ожидаемая техника не обнаружена на ≥3 пригодных кадрах; явно исключённая техника без разрешающей параллельной работы; подтверждённый этап не соответствует плану; завершение не подтверждено к дате; недостаточно данных. Без дубликатов, с зоной, работой, периодом, причиной, рекомендацией и кадрами.
- Интерфейс: вывод, фото и объяснение раньше технических сведений; прежний стиль; без возвращения удалённой технической карточки.
- Проверки всех этапов, восьми классов, сложных случаев, переходов, часовых поясов, повторов, восстановления, миграций, настоящих API/БД/S3/модели; headless laptop/mobile.
- Релиз: отдельная ветка → коммиты → push → PR → независимое ревью → зелёный CI → merge → backup → deploy → проверка установленного сервиса. При провале откат приложения без автоматического отката данных.
- HTTPS и общий код защищают API и изображения. Платные эксперименты: не более 1000 ₽ суммарно, предварительное резервирование верхней оценки; неизвестная стоимость запрещает вызов.
- Русскоязычный пакет, презентация/PDF, воспроизводимый локальный запуск, проверенные демонстрационные случаи на 8–10 минут.
