# Покрытие требований

Исходная база: `10eef28553db4260724c8c86152d7a30f8ddfb45`. Эта таблица отделяет наличие кода от приёмки.

| Требование | Реализация / источник | Доказательство и статус |
|---|---|---|
| Исторические планы, кадры, повторные запуски | backend/app/adapters/postgres.py; миграции | Регрессионные тесты новой версии ещё выполняются |
| 377 работ каталога | backend/app/application/site.py; исходный XLSX | Исходный файл сохранён, SHA привязывается при импорте |
| Восемь этапов и подтверждение техники | Реализация в отдельной ветке | Проверка новой версии не завершена |
| Переходы и параллельные работы | backend/app/domain/site_analysis.py | Выявлен дефект пересечения всей серии; исправление и регрессии в работе |
| Восемь классов, рамки и гипотезы | profiles/grounding_dino_v2.py | Экспериментальный адаптер, допуска нет |
| Независимая разметка | evaluation/expansion/README.md | Блокер: только машинные предложения, группы происхождения неизвестны |
| Выбор локального/облачного профиля | Приёмочная кампания | Не выполнен на восьми классах; старые метрики неприменимы |
| API + PostgreSQL + S3 + настоящая модель | Изолированный тестовый контур | Полная приёмка нового профиля не выполнена |
| HTTPS и код жюри | infra/deploy | Старый сервер открыт по HTTP; новый выпуск не опубликован |
| CI, PR, merge | GitHub | На исходной базе workflow отсутствовал; доставка не завершена |
| Презентация и документ | scripts/build_submission_pdfs.py | Документы описывают ограничения, не подтверждают допуск |
| Четыре демо и галерея | demo-cases/ | Проверенных случаев новой версии пока нет |

Метрики классификации, локализации, повторяемости и задержек должны публиковаться отдельно. Успешная сборка и тесты логики не доказывают качество модели.
