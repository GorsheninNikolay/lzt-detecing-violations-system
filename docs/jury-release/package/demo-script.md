# Сценарий показа: 8–10 минут

Статус: структура выступления. Не является исполняемым подтверждённым сценарием: файлы приёмочных случаев, точные значения полей и реальные результаты пока не утверждены. Непроверенные фотографии намеренно не включены в `demo-cases/`.

| Время | Действие после приёмки | Что объяснить |
|---|---|---|
| 0:00–0:30 | Открыть проект, зону и точную ревизию плана | «Сравниваем наблюдения с подтверждённым планом одной зоны». |
| 0:30–2:30 | Загрузить проверенный случай соответствия | «На относящихся к работе кадрах ожидаемая техника обнаружена». |
| 2:30–4:30 | Загрузить проверенный случай необнаружения | «Три пригодных кадра дают повод проверить работу, но не доказывают отсутствие на всей площадке». |
| 4:30–6:00 | Показать явно исключённую технику | «Для этого времени ни одна параллельная работа не разрешает этот класс». |
| 6:00–7:00 | Показать недостаточные данные | «Сервис не делает уверенный вывод, когда материала недостаточно». |
| 7:00–9:00 | Показать остальные этапы, галерею, историю и обработку сигнала | «Каждый результат сохраняет кадры, ревизию плана и сведения о модели». |

Перед допуском показа дополнить каждую строку точными файлами в порядке загрузки, временем со смещением, значениями полей, ожидаемым экраном и ссылкой на `verified-results/`. При потере связи открыто показать сохранённый результат; не выдавать его за текущий анализ.
